# Floorplan

Draft rooms, rotate them, and reach the Vault before your Steps run out. A mobile-first roguelike puzzle game in plain HTML/JS.

- Play: open `floorplan/index.html` through any static server (e.g. GitHub Pages at `/floorplan/`).
- Tests: `cd floorplan && node --test tests/*.test.mjs`
- Balance sim: `node tools/sim.mjs 300`
- Screenshots: `node tools/screenshot.mjs`

See `DESIGN_NOTES.md` and `BALANCE.md`.
